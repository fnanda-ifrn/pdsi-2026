# Projeto de Desenvolvimento de Sistemas para Internet 2026

## Catálogo dos projetos trabalhados na disciplina de PDSI - ano 2026

### Gabarita IF v2
- Equipe: [Anna Beatriz](https://github.com/beagginn), [Gabriela Maia](https://github.com/gabrielafmaia) e [Willianny Ritchelly](https://github.com/WilliannyLima)
- Descrição: Gabarita IF é um sistema educacional desenvolvido para apoiar estudantes na preparação para o Exame de Seleção do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Norte (IFRN). Este projeto é a continuação do Projeto Integrador. Nesta nova versão, os principais objetivos são melhorar as funcionalidades do sistema e avaliar a usabilidade a partir de testes aplicados com o público-alvo.
- Github: https://github.com/gabrielafmaia/gabarita-if
